# AMDGPU CoExec Scheduler Perf Report

Warm cycle counts of the innermost hot loop for each corpus kernel, measured by the AMDGPU static simulator, comparing the CoExec scheduler off versus on (with per-kernel tuning).

- llc: `LLVM version 24.0.0git`
- Generated by: `perf_test.py --report`

Lower is better. The `Δ` column is relative to **Off** (negative = faster).

## Configurations

- **Base** (shared by all): `-mtriple=amdgcn-amd-amdhsa -mcpu=gfx1250 --amdgpu-enable-static-simulator=1 --amdgpu-expert-scheduling-mode --enable-post-misched=0`
- **Off**: base only, default scheduler.
- **On+tuned**: base + `--amdgpu-sched-strategy=coexec --amdgpu-anti-hints-for-va-vdst` + the per-test flags from each kernel's `note.txt` Flags section.
